OSS project spotlight

Mantine DataTable

The lightweight, dependency-free table component that brings datagrid-like functionality to data-rich user interfaces built with Mantine UI framework, with dark-mode support and intuitive Gmail-style additive batch rows selection out of the box.

Since August 2022

Lightweight yet customizable

Supports asynchronous data loading, pagination, intuitive rows selection, column sorting, custom cell data rendering, context menus, row expansion, nesting and more.

TypeScript based

The entire codebase is written in TypeScript, options are well typed and documented with JSDoc, so you can build type-safe applications with confidence.

Free and open-source

Released under the MIT license, same as Mantine, so you can freely build fantastic data-rich applications with it.

Use anywhere

Works in any modern React framework supported by Mantine, such as Next.js, Vite, React Router or TanStack Start.

Trusted by awesome companies and developers

Used and trusted by developers across the world working in successful startups and projects: 1,250+ GitHub stars, 30 contributors, 249 releases, a legacy version still maintained for teams that can't upgrade yet, and over 500k monthly NPM downloads in October 2026.
